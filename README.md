# Финансовый трекер

Программа для учёта доходов и расходов.

## Возможности:
- Добавление доходов с категориями.
- Добавление расходов с проверкой баланса и категориями.
- Просмотр баланса.
- Просмотр истории операций.
- Статистика (общий доход, расход, количество операций).
- Сохранение данных в файл.

## Как запустить:
1. Установи Python 3.
2. Скачай файл main.py.
3. Запусти командой: python main.py

## Технологии:
- Python 3
- Работа с файлами (open, read, write)
